The project involved the design and implementation of an integrated security system for the Electronics Laboratory of the School of Engineering at Aristotle University of Thessaloniki.

The system is based on a Raspberry Pi 4 Model B, which acts as the central control unit and communicates with several subsystems responsible for monitoring different aspects of the laboratory's security.

The system includes a laboratory identification subsystem, a monitoring subsystem for the laboratory's key holders, and a motion detection system. It also records relevant data in files and maintains continuous communication with a Mattermost server, providing a way to monitor and keep track of system events.

The main objective of the project was to develop a centralized solution that combines multiple security mechanisms into a single system.
